# Nova

Nova 是一款面向个人创作者的中文 AIGC 音视频创作工作台。它把多家模型接入、提示词管理、素材归档和费用预估放在同一个本地私有空间，帮助创作者从灵感整理、参数配置到生成结果管理完成一站式创作。

项目基于 `stitch_studio` 界面原型和产品方案实现，采用 Next.js 与 SQLite，支持本机运行，也可通过 Docker 部署。界面使用石墨黑与薄荷绿视觉主题，并提供适配桌面与移动端的创作、提示词和账户管理页面。

## 项目介绍

Nova 希望解决多模型创作流程分散的问题：创作者可以在一个工作台中选择视频或配音模型，使用可复用的提示词模板，查看生成费用预估，并把任务与素材保存在自己的项目空间。模型账户由用户自行绑定，凭据在服务端加密存储；平台不会用模拟余额或虚构扣款填补厂商未公开的数据。

它适合需要反复制作短视频、探索不同模型效果、积累提示词资产，或希望把个人创作数据保存在自有设备上的创作者。当前版本以单人本地工作台为主，厂商支持范围和功能边界见下文。

### 快速使用流程

1. 首次打开工作台时，设置至少 10 位的本地访问密码。
2. 前往“模型与密钥”，绑定自己持有的服务商账户凭据，并按需测试连接或查询额度。
3. 在视频或音频创作页选择已接入的模型，编写提示词或配音文案；也可以调用已绑定的 DeepSeek 优化提示词。
4. 配置画幅、分辨率和时长，查看费用预估后提交任务。视频时长可拖动滑块调整，具体选项以所选模型支持范围为准。
5. 在任务记录中查看状态、载入历史参数或下载结果；可将常用提示词保存到资产库，按分类和标签复用。

### 交互与界面

- 所有工作台页面以中文展示，模型和服务商名称保留官方名称，方便识别。
- 页面切换、卡片、菜单、弹窗和操作反馈提供轻量过渡动画；遵循系统“减少动态效果”设置。
- 视频和音频工作台共用提示词与生成参数区域；输入提示词后可直接查看可用的模型、账户和预估费用。

## 本机启动

需要 Node.js **22.13+**，推荐 Node.js 24 LTS。

```powershell
cd D:\code\AIGC
npm ci
npm run dev
```

打开 http://127.0.0.1:3000 。首次进入时自行设置至少 10 字符的密码；没有预设生产密码。

Windows 也可以双击 `启动Nova.cmd`。`npm run dev` 同时启动 Next.js 与持久化任务 Worker。关闭该终端会结束两个进程。没有排队任务时 Worker 不调用生成接口。

生产运行：

```powershell
npm run build
npm run serve
```

独立调试时可分别执行 `npm run dev:web` 和 `npm run worker`。Web 与 Worker 必须在同一项目工作目录启动，或设置一致的 `STUDIO_DATA_DIR`。

## 当前实现

- 视频工作台：提示词、模型与账户、画幅/分辨率、可拖动时长滑块、生成数量、价格预估、参考图上传、持久化任务和结果下载。
- 提示词优化：绑定 DeepSeek API Key 后，可对视频提示词或配音文案发起优化；发送前可检查原文，优化结果需手动确认才替换。DeepSeek API 费用由厂商直接结算，当前不计入本站费用中心。
- 音频工作台：文本配音、音色 ID、费用预估与试听下载。
- 提示词库：三级分类增删改查、标签、搜索、模型筛选、收藏、模板 CRUD/复制、变量表单/实时预览、历史版本与回滚、回收站、JSON 导入导出。
- 账户：多厂商、多账户、加密凭据、Key 尾号、测试连接和官方额度查询；未接入能力明确提示。
- 项目素材：项目创建、私有上传、预览、下载、素材删除、任务快照。
- 费用：月预算、预留估算、厂商分布、费用筛选、CSV 导出。实际扣费未获得时保留 `null`，不会伪造成 0。
- 安全：首次密码设置、scrypt、随机 HttpOnly 会话、同源校验、上传魔数校验与限制、服务端 AES-256-GCM 凭据加密。
- Worker：SQLite 原子预算预留、全局/账户并发控制、查询与生成分离；不确定提交不会自动重试，避免重复扣费。

首屏与内置模板的图片来自用户提供的 Stitch 原型，是**视觉参考**，不表示已经生成视频。初始无真实账户、余额和收费生成任务。

## 厂商能力边界

| 厂商 | 生成适配 | 无付费探测 | 额度查询 |
|---|---|---|---|
| DeepSeek | 提示词优化（DeepSeek Flash） | 官方余额接口 | 官方 API 余额（CNY/USD 分开） |
| 火山方舟 | Seedance 2.5 / 2.0 Mini；文字、首帧图 | 官方模型接口 | 云账户需独立账单授权，当前提供官方入口 |
| 阿里云 | Wan 3.0 / Prime，北京 Workspace；文字、首帧图 | 不主动发起付费测试 | 当前提供官方账单入口 |
| MiniMax | H3 / Lite 文生视频；Speech 2.8 配音，中国大陆账户 | 不主动发起付费测试 | 当前提供官方账单入口 |
| Runway Dev | Gen-4.5、Kling 3.0 Pro 渠道；文字、首帧图 | 官方组织接口 | API credits |
| ElevenLabs | Eleven v4 配音 | 订阅接口 | 当前周期字符额度 |
| Vidu | 视频生成待扩展 | 额度接口 | 官方资源积分 |
| 可灵直连、Google、xAI | 目录与报价快照，生成待扩展 | 待扩展 | 当前提供官方入口 |

这是已实现的请求/任务适配范围，**不是已用实际 Key 联调通过的承诺**。本次没有用户的厂商 Key，未执行收费生成；接口请求结构、鉴权、解析与错误恢复通过离线契约测试验证。真实权限、模型可用性和价格仍需使用自己的账户小额联调。

- 阿里云账户的附加字段填写 **Workspace ID**，本版仅允许北京地域，避免地区和方案价目不匹配。
- MiniMax 本版生成仅使用中国大陆价目与 `api.minimax.cn`；不把人民币价目套到国际账户。
- H3 固定为原生有声输出；本地参考图到 H3 的安全传输尚未实现，因此界面只开放文生模式。
- 首帧图支持受限大小的数据 URI；Runway 为满足编码后 5MB 上限，原始图片限制约 3.7MB，其他传输限制以接口校验提示为准。
- Gen-4.5 提供 16:9 / 9:16 无声视频；没有伪造的音轨开关。
- 音乐、音效、字幕与 FFmpeg 成片合成属于后续扩展，当前音频页实际实现的是配音。
- 不确定提交状态需要去厂商控制台核对；不会自动重新提交。已提交任务仅在 Runway 接口支持时可远程取消，其他厂商不假装退款或取消。

## 价格与预算

报价为产品方案 **2026-10-24** 快照，包含来源和核验日期；美元预算换算可在设置页调整。活动过期或厂商改价后，应先更新 `src/shared/catalog.ts`，再继续生成。

本地预算用人民币估算，按 **Asia/Shanghai** 的日/月边界计算。每个生成条目独立预留预算；未核对的失败/不确定任务保留占用。本站无法限制其他客户端使用相同厂商账户产生的消费。

当前没有官方扣款同步与人工对账操作；任务 `actualCost` 未确认时显示待核对。该版本不应作为正式财务账簿。

## 存储与部署

本地版采用 **Next.js + SQLite WAL + 独立 Worker**，以便不安装数据库服务即可启动。产品方案中的 PostgreSQL/Redis/S3 是团队或多实例部署扩展方向，当前不是已交付能力。不要把同一个 SQLite 数据目录放在不支持锁语义的网络文件系统，也不要同时启动多个 Web 副本。

默认运行时目录：

```text
data/
  studio.sqlite       用户、模板、分类、账户、任务与预算
  studio.sqlite-wal   WAL 运行文件
  studio.sqlite-shm   WAL 运行文件
  master.key          自动生成的加密主密钥
  assets/             私有上传与生成结果
```

代码仓库和 Docker 构建忽略整个 `data/` 与环境文件。备份时停止 Web 与 Worker，完整复制 `data/`；主密钥必须保留，丢失后无法恢复已绑定 Key。生产可通过 `STUDIO_MASTER_KEY` 把主密钥独立保管，具体见 `.env.example`。

默认只接受 loopback 访问源。非本机部署设置精确的 `STUDIO_PUBLIC_ORIGIN=https://你的域名`，经 HTTPS 反向代理；不得直接公开开发服务器。没有集成多用户团队权限。

Docker 配置提供持久卷、本机端口绑定和非 root 用户：

```powershell
docker compose up --build -d
```

该命令会构建镜像并启动应用；交付检查未实际构建 Docker 镜像，宿主机 Node 方式已构建验证。

## 代码结构

```text

src/components/       创作工作台、提示词、账户、项目、费用、设置

tests/                领域和服务契约测试
public/media/         原型提供的视觉参考
stitch_studio/        用户原型，保留原件
```
