# Nova Studio Implementation Plan

> **For agentic workers:** Use subagent-driven-development for the server task and final review; the owning agent integrates and implements the interface.

**Goal:** 根据现有方案与 Stitch 原型构建可启动的个人音视频创作网站。

**Architecture:** Next.js App Router、TypeScript、独立后台任务 Worker。个人本地版以 SQLite WAL 提供持久化任务与数据，减少 PostgreSQL/Redis 的启动依赖；迁移到团队部署时再切换独立数据库与队列。

**Tech Stack:** Next.js, React, Radix Dialog/Tabs, Lucide, node:sqlite, Node crypto, tsx tests。

## Global Constraints
- 保留 D:/code/AIGC/stitch_studio 原型和已有方案文件。
- 中文界面，遵循 DESIGN.md 的石墨黑、薄荷绿与三栏布局。
- Key 仅服务端加密保存，客户端不返回明文。
- 不伪造生成、连接、余额、进度或实际扣款。
- 没有用户提供的 API Key 时不执行收费生成。
- 模板、模板版本和实际任务提示词分别保存。
- 价格来自方案快照，显示来源和核验日期；不称为实时价格。
- 本地私有部署优先；不发布外网网站。
